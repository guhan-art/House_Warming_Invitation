# Housewarming Invitation, with Extra Sparkle

A bright, animated housewarming invitation for **Subramanian & Ramya**. I made this apart from my core work, because apparently a family invitation needed a sunrise, confetti, a countdown, and a little theatrical entrance.

This is a tiny one-file website with a very large festive personality: sunrise colors, Tamil welcome text, silhouettes, falling confetti, a scrolling message, and a home elevation reveal. No framework. No build pipeline. Just HTML, CSS, JavaScript, and unreasonable enthusiasm.

## The invitation, in the important bits

- **When:** Sunday, 22 November 2026 at 7:00 AM
- **Where:** 7A, 4th Cross Street, Mangala Nagar, Porur, Chennai - 600116
- **Who:** Subramanian & Ramya, with Guhan & Kumaran

The invitation includes a live countdown, a Google Maps route, a Google Calendar link, a venue QR code, and the Tamil welcome text **புதுமனை புகுவிழா**. In other words: it looks dramatic, but it is also genuinely useful.

## Open the little festival

The site is live at:

## Run it locally

No build step or package install needed. Open `index.html` directly, or serve this folder with a simple static server:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Made with a little mischief

Plain HTML, CSS, and JavaScript, with Google Fonts and embedded visual assets. One self-contained page, no framework, no unnecessary machinery, and enough motion to make a static invitation feel like it arrived wearing sunglasses.
